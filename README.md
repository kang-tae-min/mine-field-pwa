# 광산 현장조사 PWA

ZIP을 풀고 이 폴더의 파일을 GitHub 저장소 최상위에 올리세요. Settings > Pages > Deploy from a branch > main > /(root) > Save로 배포합니다. HTTPS 주소를 iPhone Safari에서 열고 공유 > 홈 화면에 추가를 선택하세요. 최초 온라인 접속 후 오프라인 재실행을 확인하세요.

경사방향과 경사각을 정수로 직접 입력하고 조사 지점을 입력해 저장합니다. 기록은 이 브라우저의 localStorage에 보관되며 JSON 백업은 기존 기록 뒤에 추가하는 방식으로 복원합니다. CSV는 표 데이터용입니다. 저장소 삭제, 기기 변경 등에 대비하여 JSON을 자주 백업하세요.

센서는 휴대전화의 방위와 기울기 참고값만 표시하며 지질면 자세로 변환하지 않습니다. 자북과 진북 차이, 금속 및 광산 환경의 자기 간섭과 기기 자세에 주의하고 검증된 지질컴퍼스와 비교하세요. 사진 저장은 지원하지 않습니다. GPS는 HTTPS와 권한이 필요하며 갱내에서 사용할 수 없거나 부정확할 수 있습니다. 수평면은 방향이 정의되지 않습니다. 수직면 경사방향은 입력한 측을 그대로 표기합니다. 방위는 8방위로 반올림합니다.
