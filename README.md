# 광산 자세 측정 PWA

실시간 휴대전화 방위와 화면면 기울기를 표시합니다. iPhone에서 처음 측정 버튼을 누르면 센서 권한을 요청하며, 센서 표시가 시작되면 측정 버튼을 다시 눌러 저장합니다. 사진은 선택 사항이며 촬영 또는 선택 후 측정합니다. 사진은 기기 저장 공간을 절약하도록 JPEG로 축소됩니다. JSON 백업에 사진이 포함되며 CSV에는 포함되지 않습니다. 저장 공간 부족에 대비해 정기적으로 JSON을 백업하세요.

경사방향/경사각은 실험적인 추정치입니다. iPhone을 세로로 두고 화면을 면에 붙입니다. 수평 및 수직 근처에서는 방향을 표시하지 않습니다. iPhone 하드웨어, 센서·자기 간섭, 갱내 환경, 자북과 진북의 차이 등으로 오차가 발생합니다. 실제 기기와 지질컴퍼스로 검증되지 않았으므로 현장 안전 판단에 사용하지 마세요. 화면 방위는 iPhone 자북 기준입니다.
